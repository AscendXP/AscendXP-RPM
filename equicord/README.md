# Equicord

The other cutest Discord client mod.

## Installation

### openSUSE

[**Click here to install Equicord on openSUSE**](https://software.opensuse.org/package/equicord?search_term=equicord)


### Fedora

```bash
sudo dnf copr enable ascendxps/AscendXP
sudo dnf install equicord
```

## Usage

Launch **Equicord** from your application menu or run:

```bash
equicord
```
